# Communio

Communio is a Catholic prayer companion built with Flutter. It offers a daily saint reflection, searchable saint profiles, devotion scheduling, a feast-day calendar, prayer intentions, reminders, saved saints, and profile preferences.

## Run locally

```sh
flutter pub get
flutter run
```

The app's sample account, preferences, saved saints, and schedules are kept in memory for this prototype; they are not connected to an authentication or notification service.
